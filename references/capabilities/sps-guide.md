# 能力卡：SPS 卫生性能标准合规指南（FSIS《Sanitation Performance Standards Compliance Guide》，2016-03-04 版）

> 源文件简称：【SPS】= FSIS-SPS-Compliance-Guide-2016.md｜【416】= 9-CFR-Part-416-2026eCFR.md
> 本卡是 416.1–416.6（静态底线/SPS 性能标准）的"怎么做"层——告诉企业 FSIS 官方认可哪些达标路径，与 ssop-416.md（体系层）互补。

## 定位
解决"某项 SPS 底线（厂区/虫害/建筑/照明/通风/管道/污水/供水回用/更衣/设备/卫生操作/人员）官方认可怎么达标"的问题；特别覆盖 416.2(g) 回用水的分级规则与监测行动限——这是整本指南最重的干货。注意：指南给的是**推荐做法**，不是硬性要求（见下"核心机制"）。

## A2 — 触发场景

### 用户会在什么情境下遇到这类问题？
- 企业要知道某项 SPS 底线（厂区/虫害/建筑/照明/通风/供水回用/人员）官方认可怎么达标。
- 厘清 416.2(g) 回用水分级规则与监测行动限，以及“指南推荐值 ≠ 硬性要求”。
### 语言信号（用户的话里出现这些就应激活）
- “SPS 怎么达标”、“回用水 / 循环水”、“卫生性能标准”、“监测行动限”、“指南推荐值能用吗”。
### 与相邻能力卡的区分
- 与 ssop-416（416.1–416.6 体系层）互补——本卡是“怎么做”层、它是“体系义务”层；与 ltd-sanitation（清洁频率）相关但主题不同。

## 法定依据（逐条 + 一句话核心要求）
指南逐条复用 416 正文，并附四层解读：条文原文 → Comments（FSIS 补充与指令引用）→ Food Code（1999 FDA 食品法典对应条）→ Other Sources（BOCA/SBCCI 等建筑规范）。以下列关键条款与指南增补：

- **§416.1 总则**：官方企业须足以**防止不卫生状态**并**确保产品不被掺假**。指南 Comments 明确：在不卫生条件下产/存的产品即 adulterated（依 FMIA/PPIA）。(【SPS】§416.1；【416】§416.1)
- **§416.2(a) 厂区与虫害**：须有虫害管理计划；药剂须 EPA 依 FIFRA 注册、按标签使用；指南 Comments 提及检查员可要求企业提供**书面厂界划定**（原 Directive 7640.1，已下架但实践沿用在指南描述），且**厂界外起源的掺假责任仍归企业**。(【SPS】§416.2(a) Comments；【416】§416.2(a))
- **§416.2(b) 建筑**：墙/地/顶耐用防潮、开口防蝇鼠、可食/不可食**separate and distinct**；指南 Comments 允许在采取时空分隔与严格管控时同室处理可食与不可食。(【SPS】§416.2(b) Comments；【416】§416.2(b))
- **§416.2(c) 照明**：作业/检查/洗手/更衣区照度充足；指南 Comments 提醒 307.2、381.36 对检验员与再加工站的照度要求仍有效。(【SPS】§416.2(c) Comments；【416】§416.2(c))
- **§416.2(d) 通风**：控制气味/蒸汽/冷凝；指南 Comments 引 FSIS Notice 31-98 把冷凝分三类——无需行动 / 预期且由企业控制 / 必须行动（如冷凝滴入胴体或裸露产品）。(【SPS】§416.2(d) Comments；【416】§416.2(d))
- **§416.2(e) 管道**与 **§416.2(f) 污水**：六项 plumbing 义务；污水入独立系统或私建系统需州/地方卫生当局批文备查。(【416】§416.2(e)(f)；【SPS】对应 Food Code)
- **§416.2(g) 供水与回用**：见下"核心机制"专节。(【416】§416.2(g)；【SPS】§416.2(g) Comments + ICE/BRINE/COOK-CHILL/PROPYLENE GLYCOL 等回用小节)
- **§416.3 设备 / §416.4 卫生操作 / §416.5 人员卫生 / §416.6 U.S. Rejected 封签**：指南逐条给 Food Code 对应条与实操建议；416.4(c) 化学品安全证明须供 FSIS 调阅，416.6 封签只有 Program employee 能摘。(【SPS】§416.3–416.6；【416】§416.3–416.6)

## 核心机制（监管逻辑怎么运转）
1. **性能标准 = 定目标不定手段**：1999-10-20 终版规则（64 FR 56400）确立 SPS，只规定"要达到的目标"，企业可据产量工艺自定义方法。(【SPS】Introduction)
2. **指南做法不是要求**：指南明确"本文件的具体卫生做法不是要求"；照做≈大概率合规，不照做但达成目标同样合法；FSIS 验证的是性能标准本身而非是否照搬指南。(【SPS】Introduction 末段)
3. **§416.2(g) 回用水六分层级**（法规原文）：① 供水须符合 40 CFR 141（国家一级饮用水条例），市政水备查水报告、**私井至少每半年换验适饮证明**；② RTE 用 chil/cook 的水/冰/溶液（盐水、液体烟熏、丙二醇）可同用途回用，须无致病菌与粪大肠菌群；③ 生产品 chill/wash 回用须降污染，**接触过生产品的回用水不得用于 RTE**；④ onsite 高级污水处理且从未接触人类排泄物的回用水可用于生产品（不得配料），接触面须用饮用水**单独最终漂洗**；⑤ 从未接触人类排泄物且无致病菌的水可用于不接触可食产品的场景（冲槽底、栏舍、笼具等）；⑥ 不满足以上者不得用于可食区。(【416】§416.2(g)(1)–(6))
4. **回用监测行动限（指南补充，举例）**：
   - **冰回用**：打包禽肉用过的冰可回用于重新包装生整禽/部件，须自由排水收集、回用冰与新鲜冰标识区分、装不透水密封容器防直接接触、生产品用冰不得用于任何加热处理产品、无可见异物。(【SPS】§416.2(g) ICE REUSE)
   - **盐水回用**：熟制产品建议监测——总菌落计数(TPC)每日 >2500 cfu/ml、总大肠菌/粪大肠菌每周阳性即超行动限；生/热处理未全熟（如培根）TPC >5000、总大肠菌 >10、粪大肠菌阳性；游离氯 1–5 ppm。(【SPS】§416.2(g) BRINE REUSE)
   - **蒸煮与冷却回用水**：冷却水 TPC 每日 >500、总大肠/粪大肠每周阳性、浊度每周 >5 NTU；蒸煮水 TPC >500、产气厌氧菌阳性、总大肠阳性、浊度 >5 NTU；氯 1–5 ppm，冷却水 ≤50°F、蒸煮水 ≥150°F。(【SPS】§416.2(g) COOK AND CHILL WATER REUSE)
   - **丙二醇回用**：TPC 每周 >500、总大肠 >10、粪大肠阳性；氯 1–5 ppm，生产时 ≤10°F、非生产时 ≤40°F。(【SPS】§416.2(g) PROPYLENE GLYCOL REUSE)
   - 初期高频监测、稳定后可降频、失控即恢复高频。(【SPS】§416.2(g) 各回用小节)

## 关键边界与易错点
① **U.S. Rejected 封签只能由 FSIS/IPP 摘除**：指南 §416.6 与 416 原文一致——贴签设备/房间在恢复可接受前禁用。(【416】§416.6；【SPS】§416.6)
② **"不卫生状态"本身即违法触发点**：§416.1 Comments 把不卫生条件下产/存产品直接定为 adulterated，无需等实际掺假结果。(【SPS】§416.1 Comments)
③ **记录保存期（416 是 6 个月 + 现场 48 小时）**：SPS 指南本身不载 SSOP 记录细则，该要求落在 416.16——至少 6 个月、现场 48 小时、24 小时可取、首字母+日期签署。(【416】§416.16)
④ **井水半年复验**：私井供水须应 FSIS 要求提供"至少每半年更新"的适饮证明（416.2(g)(1)），回用任何场景都不豁免此义务。(【416】§416.2(g)(1)；【SPS】§416.2(g))
⑤ **Pre-Op 选点六要素 / organoleptically clean / LOTO**：属 5000.4 范畴，不在本指南；但指南 §416.2(b)、§416.4 的"clean to sight and touch"理念与 organoleptically clean 一致。(【5000.4】Ch.II；详见 preop-ssop-5000.4 卡)
⑥ **LTD 低频卫生适用前提**：属 5000.5 范畴；屠宰企业禁 LTD（禽预冷器例外），加工企业可 LTD 但须自证等效。(【5000.5】I；详见 ltd-sanitation-5000.5 卡)

## 与 417/500 的交叉关系
- **与 416 SSOP**：SPS 指南只覆盖 416.1–416.6 静态底线，体系部分（416.11–416.17）由 ssop-416 卡负责；两者合起来才是完整 416 义务。
- **与 417（HACCP）**：供水/回用稳定性、冷凝控制等若写入 HACCP 计划，则同时满足 417 的 CCP/监控/验证要求；回用监测数据常作为 HACCP 验证支持证据。(【5000.5】V.C 末段)
- **与 500（执法）**：不卫生状态（insanitary conditions）是 500.2(a)(1) 监管控制动作与 500.3(a)(4) 无预警吊扣/中止的核心触发情形之一。(【500】§500.2(a)(1)、§500.3(a)(4))

## 补充要点（源文件易遗漏的细节）
- **§416.2(b) 常见不合规示例**（指南 Comments）：门缝不严进虫/尘、顶棚墙洞、可食区起皮锈/漆、墙面霉变——是企业被开 NR 的高频项。(【SPS】§416.2(b) Comments)
- **§416.2(c) Food Code 照度**：步入式冷藏/干货区 ≥110 lux（10 fc），洗手/更衣/厕 ≥220 lux（20 fc），食品操作面（刀/切片机/锯等）≥540 lux（50 fc）。(【SPS】§416.2(c) Food Code 6-303.11)
- **§416.2(a) Food Code 虫害**：灭虫灯（电击/眩晕式）须留虫于内、不得悬于食品区上方；鼠饵站须带锁防拆容器。(【SPS】§416.2(a) Food Code 6-202.13、7-206.12)
- **§416.2(e) 回流防护**：空气间隙≥供水口直径 2 倍且不少于 25 mm（1 英寸）；回流/回吸防止装置须符 ASSE 标准。(【SPS】§416.2(e) Food Code 5-202.13)
- **§416.4 卫生操作**：Food Code 提"clean to sight and touch"、烹调设备每 24 h 清洁、热力/化学两种消毒方式参考——与 Pre-Op 的 organoleptically clean 同源。(【SPS】§416.4)
- **§416.5 人员卫生**：Food Code 2-301.11/12 规定不得在非洗手池处洗手、手臂除婚戒外不得佩饰、流涕咳嗽者不得接触暴露食品、须发网。(【SPS】§416.5)

## 专家判断注记（企业最易栽的 2–3 个点）
1. **误把"指南推荐值"当强制线**：最常见——企业为"符合指南"去套 2500/5000 cfu/ml 等行动限，却不知这些是**指南建议**而非法规阈值；真正法定要求只有 416.2(g) 的"无致病菌/粪大肠、降污染"原则。反过来，若完全无监测数据，FSIS 会认为你无法证明回用合规。
2. **回用方向搞反（RTE 红线）**：416.2(g)(3) 明文"接触过生产品的回用水不得用于 RTE"。把生品预冷溢流水接去冷却熟制产品，是高频致命违规。
3. **厂界外污染责任盲区**：SPS §416.2(a) Comments 明确"即使污染起源在厂界外划定范围之外，企业仍对防止产品掺假负责"——企业常在供应商/周边环境引入的风险上推责失败。

## 审计信息
- **质量核验**：事实回源通过：§416.2(g)(3)“接触过生产品的回用水不得用于 RTE”红线、SPS 指南建议值≠法定阈值（法定仅 §416.2(g) 原则）等边界正确；厂界外污染企业仍负责（§416.2(a) Comments）归属正确。（2026-11-04 逐卡 F1 事实回源，抽样命中源文件）
