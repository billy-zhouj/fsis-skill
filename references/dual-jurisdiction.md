# 参考层：FDA（21 CFR 117）与 USDA（9 CFR 416/417）双管辖对比 + 双管辖/等效厂体系搭建

> 本文件沉淀双管辖核实成果，供"一厂两制/等效"类问题直达。条文依据：fsis/sources/（含 21 CFR 117/123、9 CFR 416/417/418/531–537/557/327 全文）。
> 升级说明（2026-11）：① 物理分隔条款修正为 §533.1（533.2 为 [Reserved]）；② 增补"外国等效体系下监督者身份"对比；③ 中国输美鲶鱼厂变体单列。

## 一、总体对比（国内官方企业视角）

| | 21 CFR 117 Subpart B（FDA） | 9 CFR 416（USDA/FSIS） |
|---|---|---|
| 主管 | FDA | USDA FSIS（**驻厂检查制 IPP**） |
| 对象 | 所有人类食品注册设施 | 官方 establishments（肉禽蛋 + 鲇形目） |
| 立法风格 | 处方式清单（9 条，117.80 最重） | 一薄一厚：416.1–416.6 底线极简 + 416.11–416.17 强制体系 |
| 体系文件 | 无强制书面卫生计划 | **强制书面 SSOP**（每日程序/频率/责任人/签字） |
| 监控 | 法规不管 | **强制每日监控**（416.13(c)） |
| 记录 | Subpart B 仅强制培训记录（117.9） | **每日记录**，存 6 个月，现场留 48h |
| 纠偏 | 概念上无 | 强制三要素：产品处置+恢复卫生+防复发 |
| 政府验证 | 周期检查（警告信/注册暂停） | **驻厂 IPP 每天验证** |
| 特有工具 | — | U.S. Rejected 封签（416.6），只有 FSIS 能摘 |
| 过敏原 | 满篇 cross-contact | 零提及 |
| 水 | "安全且卫生质量合格" | 挂钩国家一级饮用水条例；井水每半年复验 |

**哲学差异**：① FSIS 把"方法"外包给企业（自己写 SSOP），把"证据"收归官方（每日记录+驻厂验证）——SSOP 是 HARPC 预防性控制的思想前身，早 20 年实现文件化+监控+记录。② **掺假认定两边平行**：FFDCA 402(a)(4) 与 FMIA 601(m)(4) 措辞几乎逐字相同——不卫生条件下生产、可能受污染即构成掺杂（"may have become"，无需证明实际污染）；真正差异在**执法机制**——FSIS 驻厂可当场贴 U.S. Rejected 封签事前阻断，FDA 只能周期检查后事后追责（警告信/查扣）。

## 二、监督者身份对比（关键升级点）

| 场景 | 谁在现场 | 法律基础 |
|---|---|---|
| 美国国内官方企业 | FSIS 派驻 IPP（每日验证） | 9 CFR 305/306/307、5000.1 |
| 外国等效体系（如中国输美鲶鱼） | **CCA（GACC）指派官方检验员**，FSIS **不派常驻** | §557.2(a) 交叉引用 327.2；FR 2019-24055 第 173–176 行（GACC 为 CCA） |
| 口岸兜底 | FSIS 检查员 100% 入境复检 | §557.6、§557.4 |

**务必分清**：国内"驻厂 IPP"与外国等效下"CCA 指派检验员"是两套不同主体；等效体系下 FSIS 只通过**体系审计（年度记录审查 + 至少每三年现场审计）+ 口岸复检**验证，不替代 CCA 的日常官方监督。

## 三、417 vs 117 Subpart C / 123

见 capabilities/haccp-417.md 速辨表。关键点：鲇形目企业的 HACCP 经 **§537.1** 套用 417，但**危害分析须覆盖收获前**（§537.2(a)，属 **Part 537 而非 417**）——这是鲇形目相对其他肉禽的特有加项。

## 四、双管辖厂（如鲶鱼线+罗非鱼线同厂）体系搭建七步

**核心结论：物理上按 533 分隔，文件按 FSIS 要求写满——SSOP/HACCP 文件天然覆盖 FDA 侧要求，反之不成立。**

1. **管辖映射与身份拆分**：SKU 按"鲇形目/非鲇形目"拆线；鲇形目线按 532.2（申请走 304.1）拿官方资格与驻厂 IPP；标签两套制度（FSIS 标签需审批/通用批准，FDA 无预审批）分流。 另：含禽配料食品先过 **§381.15 <2% 熟禽肉豁免**——命中则不属 "poultry product"、不进 PPIA，可能整体归 FDA（见 poultry-381）。
2. **物理分隔**（**9 CFR 533.1 Separation of establishments**——注意不是 533.2，533.2 为 [Reserved]）：鲇形目线与 FDA 线物理隔断或独立作业区+错峰；冷库/原料/成品区防混放；气流排水由高卫生区流向低卫生区；工器具色标；人员动线与工服分开；不可食用物处置设施单独设计（533.4(e) denaturing）；或干脆拆两个官方编号/两栋建筑。
3. **文件一套骨架两个出口**：危害分析按产品族各做（鲇形目线必须覆盖收获前，537.2(a)）；HACCP 计划同时标注 417/123 双合规字段；SSOP 按 416.12 写满并兼作 FDA 线卫生 PRP（117 只强制培训记录，超额覆盖）；记录以 416.16 底线为准；纠偏按 416.15 三要素一表两用。
4. **基础设施从严设计**：水按 416.2(g)（饮用水标准、井水半年复验）；化学品按 416.4(c) 备好安全证明供 IPP 调阅。
5. **资质配齐**：PCQI（117.180）+ 123.10 培训者 + 417.7 培训者；召回计划一份两分支——鲇形目触发 418（24h 通知地区办），FDA 产品走 RFR 24h + 117.139 四要素。
6. **两个监工两个接口**：FSIS 侧"日报制"（pre-op 每周 2 次+每班次 1 次，贴签即时执法）；FDA 侧"学期制"（周期巡检+注册续期+PCQI 7 天复核）。内审按双节奏排。
7. **变更管理**：新增品类先做管辖判定——防"鲶鱼式意外"的唯一办法。

## 五、中国输美厂的变体（等效体系，非国内驻厂）

- **监工从 FSIS 变成属地海关（等效机制）**，变成"一个监工、两套标准"：FSIS 只在体系审计（557.2(a) 引 327.2 的 ~14 细分项）和口岸复检出现；日常官方监督由 **GACC 指派官方检验员**承担（230 号公告附件四(一) 原文证据）。
- **官方可验证性优先于企业自证**：养殖端兽药残留控制被明确纳入——附件检验检疫依据双清单引 21 CFR 530.41（禁用兽药）、556（残留限量）、558/573（饲料药物与添加剂）、589（禁用物质）【Annex 第 14–19 行】。
- **企业三步走**：海关备案 → 对美推荐注册（生产加工企业 + 储存冷库）→ 获 USDA 注册号；**每批随附海关检验证书（§557.4 九要素）**，电子证书到港前直传 FSIS。
- **产品红线**：仅 Raw Intact / Raw Non-Intact；熟制不在列。更详尽的等效要件、过渡期连续性、三红线见 capabilities/siluriformes-china.md。

## 六、边界

- 本层不展开：417 具体 CCP 设计（见 haccp-417.md）、病原减少性能标准（310 + 5000.1 Ch.IV）、APHIS 动物健康（9 CFR 94.6）。
- 等效资格/认证企业清单/产品范围**动态变化**，以 FSIS 官网 import library 与 Eligible Foreign Establishments – China 实时核对为准。
